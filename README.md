# Trump vs Stock Market

![Python](https://img.shields.io/badge/Python-3.11-blue)
![Jupyter Notebook](https://img.shields.io/badge/Jupyter-Notebook-orange)

Study project on time-series analysis of stock-market behavior during the Trump period.

## Topic

This repository explores links between political context and market dynamics using econometrics and time-series methods (ARMA, GARCH, stationarity, VAR, cointegration).

## Repository Usage

1. Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the analysis notebook:

```bash
jupyter lab scripts/explore_and_analyze.ipynb
```

## Main Files

- `scripts/explore_and_analyze.ipynb`: exploration and econometric analysis
- `report/main.tex`: report source
- `report/main.pdf`: compiled report
